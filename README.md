# حساب‌یار (HesabYar)

## نسخهٔ Android Native
نسخهٔ بومی اندروید (Kotlin/Compose/Room/Hilt/WorkManager/DataStore) در پوشهٔ [`android`](android/README.md) قرار دارد. ساخت، تست و انتشار APK/AAB از طریق GitHub Actions انجام می‌شود؛ مستندات معماری، قواعد حسابداری و محدودیت‌ها در `android/README.md` است.

## نسخهٔ وب (نمونهٔ اولیه)
یک اپ فارسی و راست‌به‌چپ برای مدیریت مالی شخصی؛ بدون نیاز به حساب کاربری، با ذخیره‌سازی محلی در مرورگر.

## امکانات نسخهٔ اولیه

- ثبت، ویرایش و حذف درآمد و هزینه با مبلغ تومان، دسته‌بندی، تاریخ شمسی و یادداشت
- نمای کلی ماهانه: مانده، درآمد، هزینه، نمودار جریان شش‌ماهه و تفکیک هزینه‌ها
- جست‌وجو و فیلتر تراکنش‌ها بر اساس متن، نوع، دسته و ماه شمسی
- بودجه‌بندی ماهانه برای دسته‌های هزینه و نمایش مصرف، باقی‌مانده و عبور از سقف
- خروجی CSV تراکنش‌های فیلترشده و پشتیبان کامل JSON با اعتبارسنجی هنگام بازیابی
- دفتر نمونهٔ واضح‌برچسب‌خورده برای آزمایش، و امکان شروع با دفتر خالی
- رابط واکن‌گرا برای موبایل و دسکتاپ، فونت وزیرمتن، تقویم شمسی و ارقام فارسی

## اجرای محلی

نیازمندی: **Node.js 22.12 یا جدیدتر** و npm.

```bash
npm install
npm run dev
```

اپ به‌صورت پیش‌فرض روی `http://localhost:5173` در دسترس است و روی `0.0.0.0` گوش می‌دهد تا پیش‌نمایش‌های proxied نیز کار کنند.

## ساخت و مشاهدهٔ خروجی تولید

```bash
npm run build
npm run preview
```

خروجی در `dist/` ساخته می‌شود. برای استقرار روی هاست استاتیک، مسیرهای برنامه (`/transactions`، `/budgets`، `/settings`) باید به `index.html` بازنویسی شوند تا BrowserRouter درست کار کند.

## آزمون‌ها

```bash
npm run typecheck   # بررسی TypeScript
npm test            # آزمون‌های واحد و کامپوننت با Vitest
npm run test:e2e    # آزمون‌های مرورگری و دسترس‌پذیری با Playwright
```

برای اجرای آزمون‌های مرورگری، یک‌بار مرورگر Chromium را نصب کنید:

```bash
npx playwright install chromium
```

آزمون‌های مرورگری مسیرهای ثبت/ویرایش/حذف، ماندگاری داده، جست‌وجو، دانلود پشتیبان، ناوبری موبایل و بررسی WCAG A/AA با axe را پوشش می‌دهند.

## داده‌ها و حریم خصوصی

- داده‌ها فقط در `localStorage` همان مرورگر ذخیره می‌شوند؛ این نسخه سرور، حساب کاربری یا همگام‌سازی ابری ندارد.
- پاک کردن داده‌های مرورگر، تغییر دستگاه یا مرورگر، و حالت‌های موقت می‌توانند داده‌ها را از دسترس خارج کنند. مرتب از بخش «داده‌ها و تنظیمات» پشتیبان JSON بگیرید.
- فایل پشتیبان حاوی اطلاعات مالی است؛ آن را محرمانه نگه دارید.
- هنگام ورود پشتیبان، نسخهٔ شِما، واحد پول، مبلغ‌ها، تاریخ‌ها، دسته‌ها و شناسه‌ها اعتبارسنجی می‌شوند. دادهٔ ذخیره‌شدهٔ خراب بدون اجازهٔ کاربر بازنویسی نمی‌شود و نسخهٔ خام آن برای بازیابی قابل دانلود است.
- اولین اجرا یک دفتر نمونه می‌سازد. برای استفادهٔ واقعی، «شروع با دفتر خالی» را بزنید.

## ساختار پروژه

```text
src/
  components/   اجزای رابط، تقویم شمسی، نمودارها و دیالوگ‌ها
  context/      وضعیت دفتر و دیالوگ سراسری ثبت تراکنش
  data/         دسته‌بندی‌ها و دادهٔ نمونه
  lib/          تاریخ شمسی، قالب‌بندی، تحلیل مالی، ذخیره‌سازی و خروجی‌ها
  pages/        نمای کلی، تراکنش‌ها، بودجه‌بندی و تنظیمات
  test/         راه‌اندازی آزمون و fixtureها
e2e/            آزمون‌های Playwright و دسترس‌پذیری
```

فناوری‌ها: React 19، TypeScript، Vite، React Router، Lucide، jalaali-js، Vitest و Playwright.

## محدودیت‌های شناخته‌شده

- واحد پول فقط تومان و مبلغ‌ها عدد صحیح هستند.
- سقف‌های بودجه ماهانه و تکرارشونده‌اند؛ بودجهٔ جداگانه برای هر ماه ذخیره نمی‌شود.
- داده‌ها بین دستگاه‌ها همگام نمی‌شوند و `localStorage` رمزنگاری‌شده نیست.
- دسته‌بندی‌ها در این نسخه ثابت هستند.
